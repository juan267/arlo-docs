---

Como **propietario** de finca, tu rol en Arlo se enfoca en la supervisión estratégica: asegurar que la operación avance según lo planeado, identificar desviaciones importantes y tomar decisiones de alto nivel.

---

## Tu Rol en Arlo

### Qué deberías hacer

- Revisar métricas clave regularmente
- Monitorear variaciones significativas
- Aprobar presupuestos y decisiones importantes
- Asegurar que el equipo use la plataforma correctamente

### Qué NO necesitas hacer

- Registrar datos operativos diarios
- Configurar formularios de sanidad
- Crear ciclos de campo
- Registrar entradas de inventario

Esas tareas corresponden a administradores y supervisores.

---

## Vista Recomendada: Dashboard

Tu punto de entrada principal es el **Panel de Control**:

```
Lo que debes revisar:

🔴 ALERTAS CRÍTICAS
   → Cualquier alerta roja requiere tu atención
   → Verifica que se hayan tomado acciones

📊 INDICADORES EN AMARILLO/ROJO
   → Costos sobre presupuesto
   → Rendimientos bajo meta
   → Cobertura de sanidad baja

📈 TENDENCIAS
   → ¿Mejorando o empeorando?
   → ¿Patrones preocupantes?
```

---

## Rutina Recomendada

### Revisión diaria (5 minutos)

```
□ Abrir Dashboard
□ Revisar alertas nuevas
□ Verificar que no hay "rojos"
□ Si hay problemas → Delegar seguimiento
```

### Revisión semanal (15-30 minutos)

```
□ Dashboard completo
□ Progreso del ciclo de labores actual
□ Costo real vs. presupuesto
□ Resumen de sanidad de la semana
□ Reunión breve con administrador si hay desviaciones
```

### Revisión mensual (1 hora)

```
□ Reporte mensual completo
□ Comparación con mes/año anterior
□ Análisis de variaciones de costo
□ Evaluación de rendimientos de cosecha
□ Revisión de inventario (valor, rotación)
□ Decisiones estratégicas pendientes
```

## KPIs que Importan

### Financieros

| KPI | Qué te dice | Preocúpate si... |
|-----|-------------|------------------|
| **Variación de costo** | Real vs. presupuesto | > 10% sobre |
| **Costo por kg** | Eficiencia operativa | Tendencia creciente |
| **Valor de inventario** | Capital atado | Crece sin razón |

### Operativos

| KPI | Qué te dice | Preocúpate si... |
|-----|-------------|------------------|
| **% cumplimiento cosecha** | Productividad | < 90% de meta |
| **Cobertura de sanidad** | Prevención | < 80% semanal |
| **Labores completadas** | Ejecución | < 90% del ciclo |

### De riesgo

| KPI | Qué te dice | Preocúpate si... |
|-----|-------------|------------------|
| **Alertas críticas** | Problemas graves | Cualquiera > 0 |
| **Tendencia de plagas** | Presión sanitaria | Creciente |
| **Stock de insumos críticos** | Continuidad | Bajo mínimo |

## Preguntas que Deberías Poder Responder

### Sobre tu operación

- ¿Estamos dentro del presupuesto este mes?
- ¿La cosecha está en meta?
- ¿Hay problemas de sanidad que requieran atención?
- ¿Tenemos los insumos necesarios?

### Sobre tu equipo

- ¿Están usando Arlo consistentemente?
- ¿Los datos son confiables?
- ¿Quién es responsable de cada área?

### Sobre el futuro

- ¿Cómo se compara este año con el anterior?
- ¿Qué tendencias debería preocuparme?
- ¿Dónde hay oportunidades de mejora?

## Cuándo Intervenir

### Intervención inmediata

```
🔴 Alerta crítica de sanidad
   → Verificar que administrador tomó acción
   → Autorizar recursos si es necesario

🔴 Costo > 15% sobre presupuesto
   → Entender las causas
   → Decidir si ajustar o continuar

🔴 Rendimiento < 80% de meta persistente
   → Investigar con equipo técnico
   → Considerar cambios estructurales
```

### Intervención programada

```
🟡 Variaciones moderadas
   → Incluir en revisión semanal
   → Monitorear tendencia

🟡 Sugerencias de mejora
   → Evaluar costo/beneficio
   → Priorizar en plan mensual
```

### Delegar

```
🟢 Operaciones rutinarias
   → Confiar en administrador
   → Revisar en reportes

🟢 Configuraciones técnicas
   → Administrador o supervisor
   → Solo aprobar si implica costo
```

---

## Delegación Efectiva

### Quién hace qué

| Tarea | Responsable | Tu rol |
|-------|-------------|--------|
| Crear rutas de sanidad | Supervisor | Solo revisar cobertura |
| Planificar ciclos | Administrador | Aprobar presupuesto |
| Registrar logs | Supervisores | No intervenir |
| Comprar insumos | Administrador | Aprobar si > límite |
| Responder alertas | Administrador | Verificar acciones |
| Generar reportes | Administrador | Revisar y usar |

### Límites de autoridad

Configura límites claros:

```
Administrador puede aprobar:
  - Compras hasta $X
  - Contratistas con tarifa estándar
  - Cambios operativos menores

Requiere tu aprobación:
  - Compras mayores a $X
  - Nuevos contratistas
  - Cambios de presupuesto
  - Inversiones en equipo
```

## Reportes para Ti

### Mensual (recomendado)

El **Reporte Mensual** debería llegarte automáticamente:

- Configurar envío el día 5 de cada mes
- A tu correo personal
- Incluye: resumen ejecutivo, métricas clave, variaciones

### Bajo demanda

Puedes solicitar:
- Comparativos con años anteriores
- Análisis de rentabilidad por lote
- Proyecciones de producción

## Preguntas Frecuentes

### ¿Necesito aprender todo Arlo?

No. Enfócate en:
1. Dashboard y alertas
2. Reportes mensuales
3. Aprobaciones cuando se requieran

Tu equipo maneja los detalles operativos.

### ¿Qué hago si veo algo preocupante?

1. No entres en pánico
2. Verifica si el administrador ya está al tanto
3. Si no, comunícate para entender y actuar

### ¿Cómo sé si el equipo usa bien Arlo?

Revisa:
- ¿Hay datos recientes? (última semana)
- ¿Los ciclos tienen logs actualizados?
- ¿Las rutas se completan a tiempo?

### ¿Puedo ver datos de años anteriores?

Sí, usa los filtros de fecha en cualquier módulo o solicita reportes comparativos.
